
# 두려움 없는 조직

- 가볍게 읽다가 내용이 좋아서 기록까지 진행
- 책에서 심리적 안정감과 안전감 단어가 번갈아 나옴
- 그러나 의도 같지 않고 실수 같아서 심리적 안전감으로 통일해서 기록

## 서문

- 에이미 에드먼슨의 병원 의료팀 연구가 잠깐 나옴
- 팀워크 좋은 팀에서 실수가 더 많이 보고된 것
- 그러나 실수가 더 많았던 게 아니라 솔직하게 드러난 것
- 그러니까, 심리적 안전감은 정보를 더 잘 드러내게 함
- 다만, 실제 의료사고 감소까지 이어지는지에 대한 증거는 부족
- 또한 심리적 안전감이 꼭 모든 환경에 필요한 건 아님
- 필요한 정보, 질문, 피드백, 의견을 잘 이끌어내기 위한 요인 정도로 보면 좋을 듯
- 개인적으로 꾸준히 학습하고 적응해 가야 하는 조직에 있기에 심리적 안전감은 필수 기반이라 생각

## 1장. 당신의 조직은 안전한가?

- 미래 할인<sup>Discouting The Future</sup>, 대인관계 위험<sup>Interpersonal Risks</sup>은 침묵의 한 이유
- 책에서는 미래 할인을 문제처럼 얘기하는데, 일반적으로는 합리적 판단이고 선호 역전이 될 때가 문제
- 저자의 심리적 안전감 정의
  - `인간관계의 위험으로부터 근무 환경이 안전하다고 믿는 마음`
- 이러한 심리적 안전감은 문제를 조기에 드러내게 하고 몰입과 추진력에도 도움

## 2장. 두려움 없는 조직은 무엇이 다른가?

### 심리적 안전감을 구축하는 세 가지 방법

토대 만들기 → 참여 유도 → 생산적 반응

### 1단계: 토대 만들기

'실패의 틀'부터 바꿔야 함.

- 실패를 부추기는 게 아니라, 실패를 통한 학습을 지지
- 진정한 실패는 실패를 통해 아무것도 배우지 않는 것
- 또, 실패가 두려워 온전한 위험을 감수하지 않는 것

다만, 실패에도 유형이 있으며, 각각 다르게 대응 필요.

- ① 예방 가능한 실패 — 규정된 절차를 지키지 않아서 발생하며 피해야 함
- ② 복합적 실패 — 여러 요소의 복합적으로 작용으로 일어나는 문제로 쉽지 않지만 철저히 대비해야 함
- ③ 창조적 실패 — 새로운 도전의 결과이며 적극적으로 권장
- 그럼에도 불구, 좋은 실패도 나쁜 실패도 늘 발생할 수 있음
- 어떤 실패를 했느냐보다 실패에서 어떤 교훈을 얻었느냐가 중요

실패 재정의 후에는, 두려움 없이 실패할 수 있도록, 아래 3가지를 인식하게 해야 함.

- ① 불확실성 — 변화를 받아들이고 지표를 보며 민감하게 반응
- ② 상호의존성 — 서로의 업무가 연결되어 있어 영향을 미침을 이해
- ③ 문제의 핵심 — 중요하지 않은 위험에 신경쓰는 대신 진짜 문제에 집중

3가지 인식보다 더 중요한 건 리더의 역할 재정의.

| | 기존 프레임 | 신규 프레임 |
| -- | -- | -- |
| 리더 | 정답을 갖고 있음, 지시함, 직원의 성과를 평가 | 방향 설정, 직원 의견 수렴해 전략 수립과 개선, 지속적 학습 환경 조성으로 목표 성취 |
| 직원 | 지시 내용 수행 | 중요한 지식과 통찰력으로 조직에 기여 |

마지막으로, 업무의 목적을 강조하는 것 역시 매우 중요.

- '나는 직원들에게 얼마나 자주, 그리고 분명하게 업무의 목적을 강조하고 있는가?'
- 목적에 집중할 때 갖은 어려움을 극복
- 공통의 목표를 추구하는 과정에서 서로 신뢰도 쌓임

### 2단계: 참여 유도하기

> 겸손하되 적극적으로 파고들어라

토대를 만들었으면, 이제 '진정한 참여'를 이끌어 낼 차례.

- 구성원이 자신을 보호하려는 건 자연스러운 현상임을 인정하고 출발
- 만약 자리 보전에 급급한 사람이 있다면, 회사가 확실한 길을 제대로 제시하지 않았을 수도
- 이 단계에서 필요한 건 ① 상황적 겸손과 ② 적극적 질문

상황적 겸손 보이기.

- 리더가 모든 정답을 아는 척하면 문제를 제기하기 어려움
- 겸손과 호기심으로 배우려고 할 때, 구성원이 안정감을 느끼고 의견을 제시
- 이건 직원들에 대한 혜택이 아니고, 생존을 좌우하는 현실적 태도이자 필수 마음가짐
- 단, 자신감과 겸손을 서로 반대 개념으로 오해하면 안 됨
- 겸손은 내가 모든 답을 모르고 틀릴 수도 있음을 인정하는 태도
- 이게 어려운 건 권력에 대한 집착 때문이라는 댄 케이블 교수 이야기 소개

적극적으로 질문하기.

- 질문의 기본은 상대방의 대답에 진정으로 의미를 부여하는 것
- 그러나 성취를 이룬 사람들은 보통 '소박한 실재론'에 빠져 있음
- 내 생각이 곧 다수의 상식이라는 인지적 편견이며, 따라서 다른 사람의 생각이 별로 궁금하지 않음
- 또한 무지해 보일까 하는 걱정 때문에 질문을 꺼리기도 함
- 질문할 준비가 됐다면 좋은 질문을 하기 위한 고민이 필요
- 아래는 폭넓게 이해하기 위한 혹은 대안을 확장하기 위한 질문

```
어떻게 그런 생각을 하게 되었죠?
사례를 들어줄 수 있나요?
우리가 놓친 건 없을까요?
다른 방법도 있지 않나요?
다른 생각 얘기해 줄 수 있는 분 있나요?
```

- 아래 이야기도 인상적

> '반대 의견 없으신가요?' 그럼 처음에는 누군가 나서서 이렇게 대답합니다. '모두 동의합니다!' 그럼 저는 다시 말하죠. '여러분 제 말에 집중하지 않으셨군요. 모두가 찬성하는 의견은 있을 수 없습니다. 반드시 다른 생각을 하는 사람이 나오기 마련입니다. 모두 처음으로 돌아가 제 의견과 반대되는 입장에서 한 번 생각해 보세요.'라고 말이죠.

### 3단계: 생산적으로 반응하기

> 실패를 축하할 각오가 되어 있는가?

이제 '위험을 무릎쓰고 내어 준 목소리'에 대해 생산적으로 반응하는 이야기.

- 지금까지는 틀 재구성 통한 안정감 토대 마련
- 그리고 상황적 겸손과 질문으로 참여 이끌기
- 이제는 생산적 반응하기
- 생산적 반응은 3가지 특징 가짐
  - ① 감사 표현
  - ② 실패라는 오명 제거
  - ③ 위반 행위에 엄격히 조치

① 일단 고맙게 여겨라, 결과는 그 다음 문제다.

- 제기된 문제에 깊이 공감하는 것과 그대로 조치하는 건 별개
- 일단 용기를 내어 의견을 준 것에 고마움을 표해야 함
- 여기서 학습 지향(↔수행 지향)과 과정 중심의 평가 이야기로 확대
- 결과로 역량을 평가 받는다면 실패 가능성이 있는 도전은 피하기 쉬움
- 노력과 좋은 과정을 평가에 반영해야, 어려움을 감수하고 도전할 수 있음
- 과정과 결과가 항상 일치하지 않는 불확실성의 시대에 더더욱 중요
- 다만, 무조건적 고마움 표현 이야기나, 다소 별개인 캐럴드웰의 이야기를 연결한 점은 아쉬움

② 실패에 씌워진 '오명'을 제거하라.

- 규칙을 어겨서 비롯된 실패는 위험
- 비난 받아 마땅한 행동, 같은 실수 반복도 마찬가지
- 도전 과정에서 배움이 있는 실패는 환영
- 실패 파티를 하는 제약 회사 이야기도 나옴
- 이는 다음의 실패도 조기에 드러나게 해 더 큰 비용을 막음
- 실패로부터 배워 같은 문제가 반복되지 않게도 함

| | 기존 프레임 | 새로운 프레임 |
| -- | -- | -- |
| 실패 | 받아들일 수 X | 도전 과정에서 만나는 자연스러운 결과 |
| 효과적 결과 | 능력 있는 직원은 실패 없음 | 능력 있는 직원은 실패를 통해 배우고 학습하며 공유함 |
| 목표 | 실패를 막는 것 | 실패를 통해 학습을 증진 |
| 프레임 구성 결과 | 실패를 숨기고 스스로를 보호 | 공개 토론, 발 빠른 학습, 지속적 혁신 |

③ 위반 행위에는 단호히 칼을 들어라.

- 계속 우려하던 부분을 여기서 다룸
- 비난 받아 마땅한 행위는 오히려 해고가 심리적 안전감에 도움될 수도
- 정책을 어긴 경우도 강력한 제재가 필요
- 회사가 정책을 매우 중요하게 여김을 드러내게 함
- 한편, 정책이 뒷받침되어 있지 않다면 반면교사의 계기로 삼는 게 생산적

아래는 실패 별 생산적 반응의 종류.

1. 예방 가능한 실패 → 교육, 절차 개선, 시스템 개편, 제도적 처벌(반복되거나 비난이 마땅한 실수)
2. 복합적 실패 → 다양한 관점에서 실패 요인 분석, 대책 마련 위한 위험 식별, 시스템 개선
3. 창조적 실패 → 실패 축하연, 실패 기념상, 교훈 얻기 위한 철저한 분석, 새로운 가설 수립, 추가 실험 논의
