
# 두려움 없는 조직

- 가볍게 읽다가 내용이 좋아서 기록까지 진행
- 책에서 심리적 안정감과 안전감 단어가 번갈아 나옴
- 그러나 의도 같지 않고 실수 같아서 심리적 안전감으로 통일해서 기록

## 서문

- 에이미 에드먼슨의 병원 의료팀 연구가 잠깐 나옴
- 팀워크 좋은 팀에서 실수가 더 많이 보고된 것
- 그러나 실수가 더 많았던 게 아니라 솔직하게 드러난 것
- 그러니까, 심리적 안전감은 정보를 더 잘 드러내게 함
- 다만, 실제 의료사고 감소까지 이어지는지에 대한 증거는 부족
- 또한 심리적 안전감이 꼭 모든 환경에 필요한 건 아님
- 필요한 정보, 질문, 피드백, 의견을 잘 이끌어내기 위한 요인 정도로 보면 좋을 듯
- 개인적으로 꾸준히 학습하고 적응해 가야 하는 조직에 있기에 심리적 안전감은 필수 기반이라 생각

## 1장. 당신의 조직은 안전한가?

- 미래 할인<sup>Discouting The Future</sup>, 대인관계 위험<sup>Interpersonal Risks</sup>은 침묵의 한 이유
- 책에서는 미래 할인을 문제처럼 얘기하는데, 일반적으로는 합리적 판단이고 선호 역전이 될 때가 문제
- 저자의 심리적 안전감 정의
  - `인간관계의 위험으로부터 근무 환경이 안전하다고 믿는 마음`
- 이러한 심리적 안전감은 문제를 조기에 드러내게 하고 몰입과 추진력에도 도움

## 2장. 두려움 없는 조직은 무엇이 다른가?

### 심리적 안전감을 구축하는 세 가지 방법

토대 만들기 → 참여 유도 → 생산적 반응

### 1단계: 토대 만들기

지금 당장 '실패의 틀'부터 바꿔라

- 실패를 부추기는 게 아니라, 실패를 통한 학습을 지지
- 진정한 실패는 실패를 통해 아무것도 배우지 않는 것
- 또, 실패가 두려워 온전한 위험을 감수하지 않는 것

다만, 실패에도 유형이 있으며, 이에 따라 다르게 대응해야 함.

- ① 예방 가능한 실패 — 규정된 절차를 지키지 않아서 발생하며 피해야 함
- ② 복합적 실패 — 여러 요소의 복합적으로 작용으로 일어나는 문제로 쉽지 않지만 철저히 대비해야 함
- ③ 창조적 실패 — 새로운 도전의 결과이며 적극적으로 권장
- 그럼에도 불구, 좋은 실패도 나쁜 실패도 늘 발생할 수 있음
- 어떤 실패를 했느냐보다 실패에서 어떤 교훈을 얻었느냐가 중요

실패를 재정의했다면, 두려움 없이 실패할 수 있게, 아래 3가지 요인을 알려줘야 함.

- 불확실성 — 변화를 받아들이고 지표를 보며 민감하게 반응
- 상호의존성 — 서로의 업무가 연결되어 있어 영향을 미침을 이해
- 문제의 핵심 — 중요하지 않은 위험에 신경쓰는 대신 진짜 문제에 집중

두려움 없는 실패를 위해 더 중요한 건 리더의 역할 재정의.

| | 기존 프레임 | 신규 프레임 |
| -- | -- | -- |
| 리더 | 정답을 갖고 있음, 지시함, 직원의 성과를 평가 | 방향 설정, 직원 의견 수렴해 전략 수립과 개선, 지속적 학습 환경 조성으로 목표 성취 |
| 직원 | 지시 내용 수행 | 중요한 지식과 통찰력으로 조직에 기여 |

마지막으로, 업무의 목적 강조가 심리적 안전감 구축에 필요한 또 하나의 요소.

- '나는 직원들에게 얼마나 자주, 그리고 분명하게 업무의 목적을 강조하고 있는가?'
- 목적에 집중할 때 갖은 어려움을 극복
- 공통의 목표를 추구하는 과정에서 서로 신뢰도 쌓임
