
# 일 잘하는 엔지니어의 생각 기법

서문을 읽기 시작하면서 제목이 이상하다고 느껴짐. 원서 제목을 보니 아래와 같음.

**How to Make Things Faster: Lessons in Performance from Technology and Everyday Life/Cary Millsap**

엔지니어링의 일반적인 생각 기법이 아니라 성능 최적화에 관한 이야기. 그리고 성능 문제를 단순히 기술적으로만 접근하는 게 아니고, 조직과 사람 속 정치적 측면을 이해하며 정말로 문제를 해결해 가는 이야기.

서문에서는 아래와 같이 표현.

> 최적화는 기술적이라기보다는 정치적인 경우가 많다. (중략) 하지만 사실 최적화의 비기술적 측면도 기술적 측면과 마찬가지로 이해와 노력이 필요하다. (중략) 정치적인 요령을 발휘하지 않고서 그런 성공 사례는 절대 만들어내지 못할 것이다.
